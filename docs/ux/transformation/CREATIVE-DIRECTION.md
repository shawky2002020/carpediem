# Creative direction

## Approaches considered

| Direction | Composition and navigation | Trade-off |
| --- | --- | --- |
| Camp noticeboard | Photo-led entry and event discovery, warm painterly color, event posters, tabs organized by event. | Closest to the venue in tone. Poster layouts reduce density for staffing and depend on cleared imagery. |
| Operations ledger | Permanent rail, dense table-first screens, compact typography and spare color. | Efficient for desktop triage, with limited expressive range. Side-by-side data collapses poorly on a phone. |
| Field desk | A strong brand panel at entry, an adaptive workspace rail, a chronological event queue with visible action counts, an airy candidate list and a tactile roll sheet. | Preserves a recognizable entry and gives each work surface its own density. Requires separate list and form compositions. |

Select **Field desk**. Event dates, decisions, and actions set the hierarchy. A quiet warm surface allows the orange in the official badge and a mango highlight to retain meaning. Deep evergreen anchors the workspace, fern carries actions, and plum-derived ink comes from the painted doors and textiles in the reference. Keep the existing self-hosted Bricolage Grotesque headings and Hanken Grotesk body type. Use the supplied campsite motif from the official badge for identity where a photograph cannot ship.

Keep the event queue typographic. Give the working date a consistent column, with critical status and the next relevant action close to the event title. Use a split workspace for the candidate roster when there is room and a single vertical sequence on phones. Keep attendance choices next to each name and the save action within reach. Bring the everyday destinations to the bottom of a phone and the full role-specific list to the workspace menu.

Linear's triage offers a reference for treating attention as a queue of decisions. Carpediem groups the actions of an event in its row and preserves the existing event permissions. [Linear triage](https://linear.app/docs/triage)
