# Carpediem brand direction — proposed

## Thesis

Calm operational software with recognizably Carpediem outdoor character. The badge communicates a camp in a landscape; the application expresses that through restrained forest color, human typography, light surfaces, useful photography, and occasional organic rhythm.

| Dimension | Working rule |
| --- | --- |
| Personality | Warm, reliable, organized, capable, outdoors-aware. |
| Visual keywords | Forest, daylight, canopy, painted hut, quiet confidence, clear action. |
| Color | Deep green carries action and identity. Off-white keeps work surfaces calm. Orange and red remain scarce accents and must never be the sole meaning of a status. |
| Photography | Use real approved locations for identity and context. Keep text off images unless a tested scrim and accessible contrast are present. No photo wallpaper behind forms. |
| Image-to-UI ratio | Most operational screens are text and controls. Use one meaningful image in entry/onboarding or location storytelling; routine list and form surfaces use none. |
| Shape | Straightforward rectangles with modest soft corners. The circular badge is reserved for the logo; avoid repeating badge shapes in controls. |
| Radius | 8 px controls, 12 px panels, full pill only for compact badges. |
| Borders | A quiet 1 px edge clarifies fields, surfaces, and separation. Border contrast increases for selected or error states. |
| Elevation | Prefer borders and spacing. Use one shallow shadow for overlays; avoid stacked card shadows. |
| Icons | One consistent outline family, 20/24 px grid and about 2 px stroke. Filled icons only when selection or status needs stronger distinction. No camping clip art. |
| Decorative assets | No generated pattern is needed yet: photographed leaves and hut painting already offer a distinctive reference. Revisit only when a real screen has a useful slot. |
| Density | Comfortable touch spacing on phones; compact metadata can expand to columns on wide screens. Avoid putting every fact in a card. |

## Official logo evidence

The rendered PDF contains large flat regions at approximately forest `#1D5041`, dark evergreen `#15281D`, orange `#F47025`, muted red `#D13531`, and white. These are raster samples of the official PDF at 144 dpi, not an assertion about native Illustrator swatch definitions. Keep `logo.pdf` unchanged and request official web exports before shipping a logo asset.

## Approval boundary

The recommended typography and primary UI palette are proposals. The original logo is established; the UI translation requires owner review using [TYPOGRAPHY.md](TYPOGRAPHY.md) and [COLOR_SYSTEM.md](COLOR_SYSTEM.md).
