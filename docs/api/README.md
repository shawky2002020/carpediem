# API Specifications & Contracts

Contains the V1 REST API surface, request/response conventions, and OpenAPI definitions for the Carpediem modular monolith.

- **Primary Persona**: Backend Architect
- **Authentication & CSRF**: Cookie authentication (`Carpediem.Session`, `HttpOnly`, `Secure`, `SameSite=Lax`) paired with `X-XSRF-TOKEN` antiforgery header on state-changing requests ([ADR-002](../decisions/ADR-002-authentication-session-strategy.md)).
- **Error Format**: RFC 9457 `application/problem+json` with deterministic `code` and `traceId` ([`ApiProblemDetailsService`](file:///c:/dev/web/Carpediem/src/Carpediem.Web/Errors/ApiProblemDetailsService.cs)).
